Treasures come in three flavors: Coins, Minor Valuables, and Named Treasures. Each have their own homebrewed rules to unlock their potential once acquired.

|                 |                                                                                                                                                                         |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Treasure        | Description                                                                                                                                                             | Gaining it’s Value                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Coins           | While there are many types of coinage, in our game, we primarily use silver (.1 gp), gold (1 gp), and platinum (10 gp) coins.                                           | Automatic. You have a value equal to the coins you receive, which can be exchanged wherever coins are used, by anybody who wants them.                                                                                                                                                                                                                                                                                                                                                   |
| Minor Valuables | There are many types of minor valuables, from gems and precious stones to small art pieces and jewelry.<br><br>Minor Valuables will always be called “Minor Valuables.” | Minor valuables are often sold and traded even in smaller towns and communities. <br><br>Though it may take a few hours to find buyers (usually one block of 4 hours), you can simply declare that you spend some time looking for buyers and you will receive their value in coins in exchange for time.                                                                                                                                                                                |
| Named Treasures | Named treasures usually consist of large or expensive objects, art pieces, and magical items.                                                                           | Named treasures are usually too big, expensive, or even gaudy to find buyers in small towns and villages. However, in a trading hub, or a big city, you can find buyers, but it takes time. The more time you take, the more interested buyers you can find. However, that might be too much of a burden for some players, so you can receive the value up front by hiring a merchant to sell it for you. They will want a cut of the price, though.<br><br>See: **Finding a Buyer**<br> |

| **Finding a Buyer**                        |                                      |
| ------------------------------------------ | ------------------------------------ |
| Time Spent Looking For Buyers              | Effect on the value of the treasure. |
| None - Hire a Merchant to Sell It for You. | -20% of the base value.              |
| 1 Day Looking for Buyers                   | You receive the item’s base value.   |
| 2 Days Looking For Buyers                  | +10% the item’s base value.          |
| 3 Days Looking For Buyers                  | +20% the item’s base value.          |
| 4+ Days Looking For Buyers                 | +30% the item’s base value.          |
